# Branding

## Single source of truth

| Layer | Module |
| --- | --- |
| Frontend | `src/lib/brand.ts` (drives `APP_NAME` in `src/lib/constants.ts`) |
| Backend | `backend/open_webui/brand.py` (drives `WEBUI_NAME`, manifest, banner, error strings) |

Components must consume these modules instead of hardcoding brand strings.
Both modules define: product name, short name, slug, primary domain,
support/contact placeholder, default description, logo paths, square icon,
favicon, PWA icon paths, theme tokens, terminal display name ("Kolb
Terminal"), and computer-workspace display name ("Kolb Computer").

## Rebranding layer

Three scripts keep the rebrand maintainable across upstream syncs:

- `scripts/apply-brand.py` — idempotent text-level rebrand of frontend source
  and all locale files (case-insensitive variant matching in locales;
  i18n interpolation variables and the About attribution are spared).
- `scripts/generate-brand-assets.py` — regenerates every static brand asset
  from `branding/original/`.
- `scripts/audit-branding.sh` — enforcement; see docs/BRANDING_AUDIT.md.

## Logo and color system

The owner-supplied assets in `branding/original/` are authoritative and are
never modified. The palette is derived from the logo's flag purple with gold
as a secondary accent, on upstream's neutral light/dark surfaces:

| Token | Value |
| --- | --- |
| Accent (flag purple) | `#8f11b1` |
| Secondary accent (gold) | `#f0b429` |
| Light background | `#ffffff` |
| Dark background | `#171717` |

## Generated asset mapping

Generated by `scripts/generate-brand-assets.py` into `static/`,
`static/static/`, and `backend/open_webui/static/`:

| Generated asset | Source file in branding/original/ |
| --- | --- |
| favicon.png (512) | android-chrome-512x512.png |
| favicon-96x96.png | android-chrome-192x192.png |

| favicon.ico | android-chrome-512x512.png (32px re-encode) |
| favicon.svg | android-chrome-192x192.png (embedded data URI) |
| logo.png (500) | logo-512.png |
| splash.png / splash-dark.png (500) | logo-512.png |

| web-app-manifest-192x192.png | maskable-icon-512x512.png |
| web-app-manifest-512x512.png | maskable-icon-512x512.png |

`user.png` (default avatar) intentionally remains the upstream neutral
silhouette; it carries no product identity.

## Brand isolation

No Tide-Bot / Changing Tides asset, string, env default, cache key,
container, volume, storage namespace, or filename may appear in this build.
The audit script and the brand unit tests (`src/lib/brand.test.ts`,
`backend/test/test_brand.py`) fail if the brands are ever mixed. All
runtime namespaces are `kolb-bot`-prefixed (compose project, network,
volumes, Redis key prefix, OTel service name), and browser/cookie state is
additionally isolated by serving the product only at `kolb-bot.com`.

## Sanctioned upstream mentions

The About settings page retains the Open WebUI copyright attribution required
by the upstream license. License files and upstream-sync docs also name the
upstream project. Everything else is a defect — run the audit.
